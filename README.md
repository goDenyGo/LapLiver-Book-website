# Лапароскопічна хірургія печінки

Статичний сайт ілюстрованого посібника за редакцією академіка О. Ю. Усенка.
Підготовлений для https://github.com/goDenyGo/LapLiver-Book-website та домену https://lap-book.liver.surgery/.

## Локальний перегляд

У каталозі сайту виконайте:

```sh
python3 -m http.server 8000
```

Відкрийте http://localhost:8000. Збірка та встановлення залежностей не потрібні.

## Публікація на GitHub Pages

1. Розмістіть **вміст цього каталогу** в корені публічного репозиторію `goDenyGo/LapLiver-Book-website`, гілка `main`.
2. У репозиторії відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Запустіть workflow **Deploy static website to GitHub Pages** у вкладці Actions (або зробіть push у `main`).
4. Перевірте адресу https://godenygo.github.io/LapLiver-Book-website/ до перенесення домену.

Workflow публікує лише явно перелічені файли сайту й `assets/`. Рукопис, PDF та матеріали приватного репозиторію для роботи сайту не потрібні.

## Перенесення домену

Лише після перевірки нової версії:

1. За можливості підтвердьте право власності на домен у налаштуваннях GitHub Pages профілю/організації.
2. У **Settings → Pages → Custom domain** вкажіть `lap-book.liver.surgery`.
3. У DNS домену `liver.surgery` замініть старий запис піддомену `lap-book` на **CNAME → godenygo.github.io** (без `https://` та без назви репозиторію). Приберіть лише конфліктні записи цього самого піддомену; записи інших сайтів і пошти не змінюйте.
4. Дочекайтеся перевірки DNS та випуску сертифіката, увімкніть **Enforce HTTPS**.
5. Перевірте сайт, зображення, переходи за якорями, електронну пошту та QR-посилання з книги. Після цього можна вимкнути хостинг Weblium.

Workflow не змінює DNS. Файл `CNAME` навмисно не доданий: домен підключається в Settings → Pages після попередньої перевірки. Canonical, Open Graph та sitemap уже орієнтовані на кінцеву адресу.

Офіційні інструкції: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## Редагування

- Тексти, автори, посилання: `index.html`.
- Дизайн і адаптивність: `styles.css`.
- Мобільне меню та шапка: `script.js`.
- Зображення й локальні шрифти: `assets/`.

Усі кнопки замовлення ведуть лише на **liversurgerybook@gmail.com**. `mailto:` відкриває поштову програму користувача; адреса також видима для копіювання. Форм, платежів, аналітики, cookies і серверної обробки персональних даних немає. YouTube і Telegram залишені як інформаційні посилання, а не канали замовлення. Збережено окреме посилання на сторінку НБУ для підтримки України.

Інформацію про старі ціни та передзамовлення прибрано; наявність читач уточнює поштою. Біографічні дані збережені за оригінальним сайтом станом на перенесення; їх актуальність можуть уточнити автори.

## Анімації та відео

Блок «Знання. Досвід. Практика.» використовує локальний `assets/lap-liver-book-promo.mp4`: H.264, 1280×720, приблизно 17 секунд. Аудіодоріжка видалена, MP4 підготовлений з `faststart` без повторного кодування відео. YouTube-програвач для фону більше не використовується.

Відео завантажується при першій появі блоку на екрані, відтворюється без звуку по колу та призупиняється поза екраном або в прихованій вкладці. Кнопка паузи зберігає позицію відтворення. Якщо браузер блокує автоматичний старт, можна запустити відео кнопкою. Локальна заставка залишається до запуску відео.

Додано одноразову плавну появу вмісту під час прокручування та легке збільшення фото при наведенні. Налаштування `prefers-reduced-motion` вимикає появу з рухом і автоматичний старт відео; користувач може запустити відео кнопкою. Без JavaScript вміст видимий, замість відео показується заставка.
